# Judge's walkthrough

Open [NOSY](https://nosy.pages.dev/) to inspect the live workspace or [Sample demo](https://nosy.pages.dev/showcase/) for an authored walkthrough. Neither requires connecting a wallet. Live provider data may be delayed or incomplete.

## Suggested review sequence

1. **Traders:** search a KOL wallet or top FOMO wallet by name or address, select a period and open details. Compare available metrics and notice that missing values remain unavailable.
2. **Tracker:** use the Sample controls to advance the scenario. Explore token participation and buying/selling observations.
3. **Signals:** advance through the scenario and inspect how the sample presents the entry and subsequent price movement. Sample multiples are simulated price changes, not achieved trading returns.
4. **Trending:** inspect attention across tokens and the available views. Sample scores demonstrate the interface; they do not prove predictive accuracy.
5. **Token research:** use **Scan a mint**, choose a token already in the Sample and inspect its report. Live scans depend on indexed data.
6. **Compare modes:** return to the live workspace. Missing coverage may produce empty or partial states. These states should not be interpreted as zero activity or zero profit.

Use **Next step** to advance sample data; it does not navigate every screen for you. **Restart demo** returns to the start, and **Exit demo** returns to the live workspace. If a link is temporarily unavailable, the repository's captured screens still document the reviewed interface, but are not proof of current service health.

## What this repository lets you verify

- The product's intended research flow, UI design and data boundaries.
- The source and behavior of two production-derived generic utilities.
- The integrity of included assets and documents using `npm run verify`.

It does not let you rebuild or audit the full private application. No claim is made that selective disclosure satisfies every event's source-code requirements; any additional judging access must be arranged with the project owner.
